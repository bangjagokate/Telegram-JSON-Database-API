📄 Telegram JSON DB - API Documentation

Gunakan Header berikut untuk setiap request:

Authorization: Bearer YOUR_API_KEY

Database Endpoints

GET /api/databases - Ambil seluruh daftar database
GET /api/db/:name - Ambil isi satu database
POST /api/db/:name - Buat database baru
PUT /api/db/:name - Timpa isi database
PATCH /api/db/:name - Patch metadata/isi database
DELETE /api/db/:name - Hapus database

Record Endpoints

GET /api/db/:name/records - Ambil semua record
POST /api/db/:name/records - Tambah record baru
GET /api/db/:name/records/:id - Ambil detail 1 record
PUT /api/db/:name/records/:id - Update total 1 record
PATCH /api/db/:name/records/:id - Partial update 1 record
DELETE /api/db/:name/records/:id - Hapus record

Contoh Usage (JavaScript Fetch)

// POST Record Baru
fetch("https://domain-anda.com/api/db/users/records", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    name: "Budi",
    email: "budi@example.com"
  })
})
.then(res => res.json())
.then(data => console.log(data));
